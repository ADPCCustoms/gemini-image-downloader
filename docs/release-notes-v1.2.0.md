## Gemini Image Downloader v1.2.0

### New
- **A redesigned, modern window** with rounded buttons, a cleaner layout and a smoother progress bar.
- **Dark mode.** The new **Auto / Light / Dark** switch at the top right follows your Windows theme by default, and remembers your choice.
- Themed pop-up messages instead of the plain Windows ones.
- The tool now remembers your save folder between runs.

### Same as before
- Runs entirely on your computer; you sign in yourself and nothing is uploaded.
- Safe to re-run: images you already have are skipped.
- Uses your installed Chrome or Edge.

### Notes
- If Windows says "Windows protected your PC", click **More info → Run anyway** (the exe isn't code-signed). Check the download against the `.sha256` file if you like.
- Unofficial tool, not affiliated with Google. If it stops working after a Gemini update, please [open an issue](../../issues/new/choose).
