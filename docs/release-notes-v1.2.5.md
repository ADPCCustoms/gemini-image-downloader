## Gemini Image Downloader v1.2.5

### New
- **Time-stamped log.** Every line in the window's log now shows the time it happened.
- **Running timer** at the top right of the window while a download runs, plus an **estimated time left** while images are being saved.
- **Time-taken summary** at the end, with how long each part took: checking existing images, opening Gemini, waiting for you (sign-in), scanning your Library, and saving images. This shows where a long run spends its time.
- **Log file.** A copy of the log is saved as `last_run_log.txt` next to the program, with an **Open log** button in the window. Useful to attach to a bug report.

### Notes
- The log file contains your save-folder path and image counts, but not private image links.
- Unofficial tool, not affiliated with Google.
