## Gemini Image Downloader v1.3.4

### Changed
- **The quick listing is now off by default.** On a real Library it took 14 minutes, about the same as the careful scan, because Gemini feeds the Library to the page at its own pace whichever way you scroll. It also stopped slightly early (3,719 of about 3,745 pictures found), so it was less complete. The careful scan is back as the default. (`--quick-listing` turns the quick listing back on.)

### Notes
- A full scan of about 3,700 pictures takes roughly 11 to 14 minutes. That time is set by how fast Gemini loads the Library, not by this tool.
- Unofficial tool, not affiliated with Google.
