## Gemini Image Downloader v1.4.1

### Fixed
- **Choosing a theme (Auto / Light / Dark) closed the program** on some PCs, and it had to be opened again by hand. The program no longer tries to switch the look while it is open. It saves your choice and reopens itself in the new look, so you only see the window close and come back. If a download is running, the choice is saved and applies the next time the program is opened, and the selector is locked until it finishes.
- If the program can't reopen itself for any reason, it says so and keeps the window open. A small `restart_error.txt` is written next to the program.
